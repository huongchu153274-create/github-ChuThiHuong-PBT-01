API đã dùng:
- Hình ảnh tải từ https://picsum.photos (image placeholder service).

Cách chạy:
- Mở các trang:
  - `gallery/loading.html`
  - `gallery/success.html`
  - `gallery/error.html`
- Hoặc chạy server:
  - `python -m http.server 8000`
  - `npx http-server . -p 8000`

Ghi chú: Picsum cung cấp hình ảnh demo không cần API key; khi chạy offline, success page vẫn tải ảnh từ mạng.
