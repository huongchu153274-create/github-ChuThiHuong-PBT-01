API đã dùng: Demo hiện dùng dữ liệu mô phỏng (no external API).

Cách chạy:
- Mở:
  - `user_directory/loading.html`
  - `user_directory/success.html`
  - `user_directory/error.html`
- Hoặc chạy server:
  - `python -m http.server 8000`
  - `npx http-server . -p 8000`

Ghi chú: Để kết nối API người dùng thật, có thể dùng `https://jsonplaceholder.typicode.com/users` hoặc một API khác và xử lý CORS.
