API đã dùng: Demo uses mock data (no external API).

Cách chạy:
- Mở:
  - `dashboard/loading.html`
  - `dashboard/success.html`
  - `dashboard/error.html`
- Hoặc chạy server:
  - `python -m http.server 8000`
  - `npx http-server . -p 8000`

Ghi chú: Để tích hợp widget thật, fetch dữ liệu từ endpoints tương ứng và cập nhật DOM.
