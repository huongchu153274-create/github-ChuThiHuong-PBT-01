API đã dùng:
- Hình ảnh mẫu lấy từ https://picsum.photos (image placeholder).

Cách chạy:
- Mở `product_catalog/index.html` trực tiếp trong trình duyệt.
- Hoặc chạy static server:
  - `python -m http.server 8000`
  - `npx http-server . -p 8000`

Ghi chú: Dữ liệu sản phẩm là mảng JS bên trong `script.js`. Không cần API key.
